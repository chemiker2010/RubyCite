# RubyCite

将一整个文件夹的学术论文自动整理成文献综述。

RubyCite 是一款面向科研人员的 AI 桌面应用程序。

你可以导入期刊论文 PDF，自动生成结构化摘要、整理研究笔记，并生成带引用的文献综述，同时所有数据都保存在你的本地设备上。

⸻

RubyCite 解决什么问题？

大多数研究人员都会花费大量时间在重复性工作上：

* 阅读大量 PDF 论文
* 提取关键研究发现
* 撰写和整理笔记
* 对比不同论文
* 撰写文献综述
* 管理参考文献

RubyCite 将这些步骤整合到一个统一的工作流程中。

你不再需要频繁切换：

* PDF 阅读器
* 笔记软件
* AI 聊天工具
* 文献管理软件

所有工作都可以在一个平台完成。

核心功能

从多篇论文自动生成文献综述

选择一组论文，然后让 RubyCite 针对特定主题生成文献综述。

生成的综述会自动包含作者-年份格式引用：

最近研究表明，基于 Transformer 的方法能够显著提高检索准确率（Smith，2023）。

你还可以导出 RIS 格式参考文献，并继续在 Word、EndNote 或 Zotero 中完成写作。

⸻

为每篇论文生成 AI 摘要

RubyCite 可以将单篇论文自动整理成摘要卡片。

每篇论文可提取为：

* 研究目标（Research Objective）
* 研究方法（Methodology）
* 主要发现（Main Findings）
* 研究局限性（Limitations）
* 个人笔记（Personal Notes）

帮助你在阅读过程中逐步建立可检索的知识库。

⸻

将 PDF 转换为可编辑 Markdown

RubyCite 能够将出版社发布的 PDF 论文转换成结构化 Markdown 文件。

提取内容包括：

* 正文文本
* 图片
* 表格
* 元数据（Metadata）
* DOI 信息

生成的 Markdown 文件不依赖 RubyCite，可以使用任何 Markdown 编辑器进行编辑。

⸻

参考文献管理

RubyCite 可以自动识别：

* DOI
* 作者
* 期刊名称
* 发表年份

并可通过 Crossref 自动补充和完善元数据。

支持导出 RIS 格式，兼容：

* EndNote
* Zotero
* Mendeley
* Word 引文管理器

⸻

本地优先 AI（Local-first AI）

所有研究资料均保存在你的本地设备上。

支持的 AI 后端包括：

* 内置 llama.cpp 模型
* Ollama
* LM Studio
* OpenAI 兼容 API
* DeepSeek 兼容 API

你可以根据需要选择：

* 本地模型推理
* 云端模型服务
